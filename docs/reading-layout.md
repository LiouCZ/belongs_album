# 图文阅读排版

`reading-layout.js` 只负责网页展示，不改写源 JSON、日期、检索内容、分组或图片。官方卡片、作品详情、整篇作品与品牌故事原文窗口共用这一套规则，直接打开静态 HTML 也能使用。

## 通用规则

- 编号作品的长括号说明从大标题降到正文，编号仍保留；短尺码括号、日期与结构不明确的标题不拆分。
- 明确的清单编号、独占一行的章节标题、品牌署名和参数行使用各自的层级。数字尺寸、年份和正文中的关键词不会当成编号或小标题。
- 星号仅在明确的参数标签前作为排版符号弱化，正文和尺寸里的星号不变。文章主题只使用已核对的文章元数据，不从破折号推测。
- “固定品类”“独立雕刻”“即兴”等明确制作类型后，若紧接短元素清单和“搭配、规格、材质”三行，则统一排成同一参数区。元素续行归在同一项；不从单个“金眼”等词语推断普通正文。补充的“制作类型、元素”标签使用样式显示并提供无障碍名称，原文字符与行序不变。
- 简短制作描述保留行序；长文分段，短诗保留断行；参数值可自动换行。网页原文窗口仍完整显示历史文字，不在排版阶段删除旧发售说明。

## 特殊作品

少数旧文的无编号多作品、诗歌与说明混排、跨字段括号、参数续行，记录在 `reading-layout.js` 的 `special` 表中。使用稳定的原图片 ID，与 `legacy:<ID>` 作品对应，不使用标题或列表位置定位。

添加特殊规则时先核对原文，使用独占一行且唯一的文字锚点；锚点不匹配时退回通用布局，不补写或猜测作品内容。标题拆分只调整显示层级，原字符与顺序必须可恢复。参数续行必须明确指定原行与续行。

## 检查

```bash
node tests/reading-layout-check.mjs
node tests/reading-layout-browser-check.mjs
node tests/detail-typography-check.mjs
```

第一项检查全量原文字符与特殊锚点；第二项在六种屏宽检查全部官方图文、搜索及 93 条故事原文；第三项保持新版公众号作品的参数、主题和玩家图文兼容。布局修改还需检查桌面与手机截图，不能仅凭没有溢出判断排版质量。
